# wxmsg 桌面界面

Tauri 2 应用: Rust 后端直接复用 `wxmsg-core`, 前端是一份静态 HTML/CSS/JS。
**不需要 Node 工具链**: 界面文件由 Tauri 直接打进产物, 前端通过 `withGlobalTauri` 拿到
`window.__TAURI__`, 因此没有 `package.json` 与打包器。

## 运行

```shell
just gui      # 用日常数据目录与平台日志位置
just debug    # 隔离数据目录与最详细日志, 可与正式实例同时跑
just dist     # 打包出 .app 与 dmg
```

## 界面能做什么

| 区域 | 内容 |
| --- | --- |
| 左栏 | 会话列表 (联系人名优先, 可搜索), 后面的数字是消息条数 |
| 右栏 | 选中会话的消息, 按时间正序 |
| 右栏开关 | `显示撤回` 会当场跑一次找回, 把被删消息标上 `撤回` 后按时间插回 |
| 底部状态栏 | 版本号, 消息库路径与密钥数量, 归档快照数量, 退出按钮 |
| 设置 | 启动时是否只留在托盘, 隐藏窗口时是否一起隐藏 dock 图标, 一次显示多少条 |

## 窗口行为

- **关闭按钮不是退出**: 窗口隐藏到托盘, 进程继续运行; 真正退出走托盘右键菜单的 `退出`, 或底部状态栏的退出按钮
- **托盘左键**显示并聚焦主窗口, **右键**弹菜单; 菜单首行是禁用的 `wxmsg v<版本>`
- 界面按 macOS 习惯做成无独立标题栏: 保留原生红黄绿按钮, 内容延伸到顶部
- 只记忆窗口大小, 不记忆位置: 换显示器或分辨率之后, 旧坐标可能落在屏幕外
- 同一数据目录只允许一个实例; 再次打开会把主窗口唤到前面
- 终端里 Ctrl+C 与托盘 `退出` 走同一条收尾路径

## 数据与日志

| 项 | 位置 |
| --- | --- |
| 数据目录 | `~/Library/Application Support/com.azazo1.wxmsg/` (可用 `APP_DATA_DIR` 覆盖) |
| 设置 | 数据目录下的 `settings.json` |
| 日志 | `~/Library/Logs/com.azazo1.wxmsg/wxmsg.log.<日期>` (可用 `APP_LOG_DIR` 或 `APP_LOG_FILE` 覆盖) |

日志按天轮转, 启动时清掉 7 天前的文件; panic 也会写进日志。
`just debug` 把这两处都重定向到 `target/wxmsg-debug/`, 因此调试实例不会碰日常数据, 也能与
正式实例同时运行。
